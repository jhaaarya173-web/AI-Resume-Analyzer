# AI Resume Analyzer

## Project Overview

AI Resume Analyzer is an AI-powered desktop application developed using Python to help users analyze and improve their resumes. The application extracts content from PDF and DOCX resumes and uses AI to evaluate the candidate's skills, experience, and profile based on a given job role or job description.

It provides useful insights and personalized suggestions to help users improve their resumes and better align them with job requirements.

## Key Features

* Upload and analyze PDF and DOCX resumes
* Extract resume content automatically
* AI-powered resume analysis
* Identify skills, qualifications, and experience
* Match resume information with job requirements
* Provide personalized improvement suggestions
* User registration and login system
* Store user data using SQLite
* Simple and user-friendly Tkinter interface

## Technologies Used

* Python
* Tkinter
* SQLite
* OpenAI / Groq API
* Pandas
* pdfplumber
* python-docx

## How It Works

1. User creates an account or logs into the application.
2. User uploads a resume in PDF or DOCX format.
3. The application extracts the text and relevant information from the resume.
4. The user provides a target job role or job description.
5. The AI analyzes the resume based on the provided requirements.
6. The application provides insights and suggestions for improving the resume.

## Project Objective

The objective of this project is to simplify the resume evaluation process using AI and help job seekers understand how effectively their resume represents their skills and experience for a particular job opportunity.
